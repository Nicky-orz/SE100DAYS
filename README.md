#### 位运算
- 当一个问题可以被拆解成若干个独立的“是/否”决策时，就能用位运算
- 位运算能快速解决集合问题
- 子集枚举	for (sub = mask; sub; sub = (sub-1) & mask) & 是交集，找子集
- 超集枚举	for (i = k; i < (1<<n); i = (i+1) | k)  | 是并集，找母集

#### 最短路
- Floyd：三重循环枚举中间点做 DP，求全源最短路，能处理负权但不能有负环，复杂度 O(N^3)
- Bellman–Ford / SPFA：反复松弛所有边（SPFA 用队列只处理被更新的点）求单源最短路，能处理负权并判负环，最坏 O(NM)
- Dijkstra：贪心每次取当前距离最小的未确定点并永久确定，只适用于非负权单源最短路，堆优化后 O(Mlog N) (贪心原理：绕路会增加距离)

#### 欧拉路径Hierholzer
- 沿未走过的边不断 DFS，走到死路(成环/成完整路径)时回溯并把节点加入路径，最后逆序输出，就得到欧拉路径或欧拉回路
- 为什么能这样做：死路说明成环/完整路径，那么回溯把环/完整路径打开，看看有没有新没走过的环能加进来(核心：多加一个环不影响连通性)
