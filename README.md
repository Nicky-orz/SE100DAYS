## 知识体系

### 数据结构

#### 数组
- 连续内存存储，支持下标随机访问
- 随机访问 O(1)，插入/删除通常 O(n)
- 是最基础、最常用的线性结构
| 变体 | 作用 |
| --- | --- |
|动态数组|自动扩容，日常最常用|
|多维数组|矩阵、网格、DP 表|
|前缀和数组|快速求区间和 O(1)|

#### 字符串

- 本质是字符序列，可看作特殊数组
| 变体 | 作用 |
| --- | --- |
|字符串哈希|快速判断子串是否相等|

#### 链表

- 由包含数据和指针的节点组成
- 内存不连续，随机访问慢O(n)
- 已知前驱或位置时，插入/删除 O(1)
- 适合频繁增删，不适合频繁随机访问

| 变体 | 作用 |
| --- | --- |
|单链表|单向遍历，结构简单|
|双链表|可前后遍历，便于删除|
|循环链表|首尾相连，适合环形调度|
|带头结点链表|简化边界处理|
|静态链表|用数组模拟链表|

#### 栈
- 后进先出
- 只在栈顶操作：push、pop O(1)

| --- | --- |

#### 队列
- 先进先出
- 队尾入队，队头出队 O(1)

| 变体 | 作用 |
| --- | --- |

#### 哈希表
- 通过哈希函数把 key 映射到桶
- 平均查找、插入、删除 O(1)。
- 可能发生哈希冲突，最坏情况可能退化到 O(n)

| 变体 | 作用 |
| --- | --- |
|链地址法|每个桶挂链表/红黑树|
|开放寻址法|线性探测、二次探测、双重哈希|
|字符串哈希|快速比较子串|

#### 并查集

- 维护不相交集合
- 用树表示集合
- 支持快速查找和合并
- 适用于动态连通性和等价关系

| 变体 | 作用 |
| --- | --- |
| 扩展域并查集 | 用有限的状态节点，把命题关系翻译成等价合并 |
|带权并查集|多维护一个“到根的距离”|

#### 二叉树

- 每个节点最多两个子节点：左孩子、右孩子
- 递归结构，天然适合递归遍历。
- 可用于表达层次关系和分治结构

| 变体 | 作用 |
| --- | --- |
|满二叉树|每个节点 0 或 2 个孩子|
|完全二叉树|适合数组存储，堆的基础|
|平衡二叉树|控制高度，保证效率|

#### 二叉搜索树 BST

- 左子树所有节点 < 根 < 右子树所有节点
- 中序遍历结果有序
- 查找、插入、删除平均 O(log n)
- 若退化成链，最坏 O(n)

| 变体 | 作用 |
| --- | --- |
|普通 BST|动态有序查找|
|AVL 树|严格平衡，查询快|

### STL

#### map

- 存储键值对 key -> value
- 键唯一
- C++ map 通常有序，底层红黑树
- 支持按 key 查找、插入、删除、遍历O(log n)

#### set

- 存储不重复元素
- C++ set 通常有序，底层红黑树
- 自动去重、自动排序
- 支持查找前驱、后继、范围查询，O(log n)
